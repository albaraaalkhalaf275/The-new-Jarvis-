# JARVIS 2026

A web-only personal AI assistant built with Next.js, Supabase, and OpenAI.

## Included

- Supabase authentication
- Persistent conversations and messages
- Memory context
- Responsive JARVIS interface
- Browser voice input and speech output
- Server-side OpenAI Responses API
- Vercel-ready Next.js structure

## Environment

Configure the Supabase URL and publishable key plus the server-side OpenAI API key in Vercel environment variables.

Never expose the OpenAI API key with a NEXT_PUBLIC_ prefix.
